# Плагины для Paper 26.1.x

| Плагин | Что делает |
|---|---|
| **ShearFrames** | Shift + ПКМ ножницами по рамке — рамка становится невидимой (повторно — видимой). |
| **FlatSigns** | Shift + ПКМ табличкой по полу или потолку — после ввода текста табличка ложится плашмя. Удар по ней ломает её и возвращает предмет. |
| **VillagerTrades** | Каждый трейд жителя — 64 сделки, затем не блокируется, а цена растёт на 25% (32 → 40 → 50 → 63 → 64, больше стака нельзя). При пополнении запасов жителя цена опускается на шаг. |
| **TreeChop** | Начинаешь ломать бревно — над ним счётчик брёвен в дереве. Каждое сломанное бревно уменьшает счётчик; когда сломано столько раз, сколько брёвен, рубится всё дерево вместе с природной листвой (лут выпадает). С Shift — как обычно. |
| **LocatorColor** | Shift + ПКМ в воздух компасом с названием «Локатор» — окно выбора цвета своей точки на панели локатора; цвет виден и в списке игроков (Tab). |
| **TraderPost** | Shift + ПКМ изумрудом по бочке — пост торговца: раз в 5 игровых дней приходит странствующий торговец, 2 дня стоит у бочки, каждые полдня меняет трейды (3 раза), потом уходит. |

## Сборка
GitHub Actions собирает все jar при каждом пуше (артефакт **plugins**).
Локально: JDK 25, `gradle build`, jar-файлы в `*/build/libs/`.
