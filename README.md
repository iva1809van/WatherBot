# ShearFrames

Плагин для Paper 26.1.x: **Shift + ПКМ ножницами** по рамке (обычной или светящейся) делает её невидимой. Повторное действие возвращает видимость.

- Право: `shearframes.use` (по умолчанию у всех)
- Ножницы теряют 1 прочность (кроме креатива)

## Сборка
Требуется JDK 25.
```
gradle build
```
Готовый jar: `build/libs/ShearFrames-1.0.0.jar` → положить в папку `plugins/` сервера.
